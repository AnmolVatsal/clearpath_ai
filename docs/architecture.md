# System Architecture

## 1. Data Layer
The system ingests patient records, diagnosis codes, procedure codes, payer metadata, and policy rules.

## 2. Intelligence Layer
The decision layer evaluates medical necessity, CPT–ICD alignment, payer requirements, documentation quality, and risk indicators.

## 3. Execution Layer
The workflow layer supports prior authorization, claims adjudication, denial handling, and simulation of policy changes.

## 4. Audit Layer
Every decision is recorded with reasoning, timestamps, confidence, and structured justification for transparent review.
